# AI Chatbot using RAG + Endee

## 📌 Project Overview
This project is a chatbot that answers user queries using Retrieval-Augmented Generation (RAG).

It uses a vector database concept (Endee) to retrieve relevant information.

## 🚀 Features
- AI-based chatbot
- Fast response
- Simple UI using Streamlit

## 🧠 Technologies Used
- Python
- Streamlit
- Endee (concept)

## ▶️ How to Run
1. Install dependencies:
   pip install streamlit

2. Run the app:
   streamlit run app.py

## 💡 Use Case
- Student assistant
- Notes chatbot
- Knowledge search

## 📌 Conclusion
This project demonstrates how AI chatbots retrieve and answer questions using stored data.
